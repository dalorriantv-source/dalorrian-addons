# Dalorrian's Addons

WoW: Forever addons by Dalorrian. Each folder goes in `Interface\AddOns`.

- Aggro Alert - a warning before you pull a mob
- Auto Opener - opens clams, loot bags and crates for you
- Chat Copy - copy chat as plain text, clickable web links
- Chat Saver - save your chat setup and load it on any character
- Combo Bar - combo points and an energy tick bar
- Crit Sounds - a sound and a big shaking number on every crit
- Crit Tracker - your best hit and crit with every ability
- Gold Bag - your gold on top of your bag bar, all characters on hover
- Loot Rolls - movable Need, Greed and Pass bars that show who won
- Scrolling Loot - what you loot floats up on screen
